01 / THE IDEA

Not a shell with rules.
A smaller surface entirely.

ReaTerm does not try to guess which Bash commands are safe. It only implements read-only inspection operations and rejects everything else.

Allowlist, not guesswork

ls, cat, grep and five other native commands. No interpreters, scripts, unknown flags, or subprocess forwarding.

POLICY / 001

Kernel-level guardrails

Linux requires Landlock and seccomp; macOS uses Seatbelt; Windows uses a low-integrity write-restricted access token. Enforcement failures stop the command.

KERNEL / 002

Scoped. Predictable. Small.

Read paths are relative to a caller-chosen root. File sizes, output and directory listing lengths are bounded. No hidden command hooks.

DESIGN / 003

02 / UNDER THE HOOD

An intentionally short path.

The parser validates the entire request. Only explicit read operations can reach the native filesystem reader after mandatory kernel confinement is installed.

03 / QUICK START

From zero to read-only.

Choose your integration. Each path uses the same compiled native engine and requires Linux with Landlock and seccomp, macOS with Seatbelt, or Windows x86-64 with a low-integrity write-restricted token.

Install the native CLI

Clone the repository and install the binary into Cargo's bin directory. Run commands directly from your terminal.

BASH
git clone https://github.com/Pro-GenAI/ReaTerm.git
cd ReaTerm
bash scripts/install.sh
reaterm ls -la
reaterm cat README.md

Cargo's bin directory must be on PATH. Alternatively, build via cargo build --release --manifest-path src/rust/Cargo.toml.

Inspect from Python

Import reaterm.run("ls -al") or use the ReaTerm class for exact argv. Python also exports OpenAI and Anthropic function-tool schemas. The Rust binary must be available on PATH or via REATERM_BIN.

BASH + PYTHON
# From the repository root, after building the native binary
python -m pip install -e src/python
python -c 'import reaterm; print(reaterm.run("ls -al"))'

Run this example from the repository root. For optional model checks, use the src/python[decision] extra.

Inspect from Node.js

Import run("ls -al") from the unscoped reaterm npm package, or use its ReaTerm class for exact argv. Both call Rust without a shell.

NODE.JS / TYPESCRIPT
// After npm install && npm run build in src/typescript
import * as reaterm from "reaterm";

console.log(await reaterm.run("ls -al"));
console.log(await reaterm.run('cat "README.md"'));

Requires Node.js 20+. See the TypeScript package source for build instructions.

05 / FUNCTION TOOLS

Give models a tool. Not a shell.

Use Python tool definitions for OpenAI Chat Completions, OpenAI Responses, or Anthropic Messages. A model requests a supported inspection command, but your application executes it and sends back the result.

PYTHON SDKOPENAI

OpenAI function calling

Import the Chat Completions schema and dispatch only the returned tool-call arguments. For the Responses API, use reaterm_tool_openai_responses.

OPENAI / PYTHON
from reaterm.tools.openai import (
    reaterm_tool_openai,
    execute_reaterm_tool,
)

# client.chat.completions.create(
#     ..., tools=[reaterm_tool_openai]
# )
# After receiving a function tool call:
# stdout = execute_reaterm_tool(
#     call.function.arguments, root="."
# )
PYTHON SDKANTHROPIC

Anthropic tool use

Pass the Messages API tool schema, then dispatch the tool_use block's input through the same read-only native executor.

ANTHROPIC / PYTHON
from reaterm.tools.anthropic import (
    reaterm_tool_anthropic,
    execute_reaterm_tool,
)

# client.messages.create(
#     ..., tools=[reaterm_tool_anthropic]
# )
# After receiving a tool_use block:
# stdout = execute_reaterm_tool(
#     block.input, root="."
# )

Tool arguments have the form {"command": "ls", "args": ["-al"]}. Only eight read-only native commands are supported. Schemas alone do not execute commands; callers must send results back using each provider's tool-call ID. Returning stdout to a provider can disclose readable files. Full tool-calling guide ↗

06 / THE BOUNDARIES

Security without
the fine-print tricks.

Read-only means the ReaTerm process does not implement writes. It is not a replacement for a trusted launcher or a confidentiality control.

Read the full threat model ↗
01

Parent shells are separate. Redirecting reaterm ls > file.txt can still create or truncate a file before ReaTerm starts.

02

Inherited descriptors matter. Landlock does not revoke previously opened file descriptors; launch it from a trusted process.

03

The root is caller-selected. ReaTerm is not a tool for hiding files inside an otherwise readable directory.

04

Linux, macOS and Windows x86-64. Other Windows architectures and 32-bit ARM are unverified. Windows token protection is thread-scoped.
